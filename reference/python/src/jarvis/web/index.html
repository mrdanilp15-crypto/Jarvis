Gesprächsprotokoll

    Zugang

    Geben Sie Ihr JARVIS-Token ein. ./deploy/start.sh zeigt es am Ende an; es steht außerdem in deploy/.env bei JARVIS_DEV_TOKENS.

    Einstellungen

    Spracheingabe funktioniert in Chrome und Edge. Deren Spracherkennung läuft über die Server von Google bzw. Microsoft – bei eingeschalteter „Jarvis“-Aktivierung dauerhaft, sonst nur nach einem Tipp auf den Kreis. Die JARVIS-Stimme (Piper) läuft lokal auf Ihrem Rechner; Browserstimmen nutzen die Sprachausgabe Ihres Systems. Vollständig lokale Spracherkennung (Whisper, openWakeWord) ist der nächste Ausbauschritt.
